SWIFT Frequency-Tracking Algorithm

Spring 2026

SystemVerilog · RTL · Fixed-Point · Verification

SystemVerilog RTL implementation of SWIFT (Sliding Window Infinite Fourier Transform), a recursive frequency-tracking algorithm targeting a ZedBoard (Zynq XC7Z020).

  • Designed fixed-point datapath modules: a combinational Q1.15 × Q9.14 complex multiplier, a 64-bin synchronous state RAM, and a coefficient ROM initialized with $readmemh.
  • Wrote a Python golden reference model and used it to generate the 64 complex Q1.15 decay coefficients stored in the ROM.
  • Developed SystemVerilog testbenches to verify complex arithmetic, fixed-point behavior, and synchronous memory timing; used waveform analysis to debug module interfaces in preparation for top-level FSM integration.

32-Bit Single-Cycle MIPS Processor

Spring 2026

SystemVerilog · RTL · Computer Architecture

A 32-bit single-cycle MIPS CPU written as modular SystemVerilog, with each component verified on its own before top-level integration.

  • Wrote the ALU (with N/Z/C/V flags), ALU control, main control unit, register file (two read ports, one write port, $zero write-protected), instruction and data memories, and sign extension.
  • Integrated the processor datapath and control path, including PC update, instruction decode, ALU operand selection, branch logic, and write-back.
  • Implemented and verified R-type (add, sub, and, or, slt), addi, lw, sw, and beq using module-level testbenches and a top-level testbench running a hand-assembled MIPS program.
